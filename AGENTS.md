# Инструкции AI-ассистентам

## До начала работы

1. Прочитай README.md и CONTRIBUTING.md. Уточни задачу и критерии приёмки.
2. Проверь `git status`, текущую ветку, `git remote -v` и аккаунт `gh auth status`. Определи исходный репозиторий и fork. Не переключай аккаунт без причины.
3. Не удаляй и не перезаписывай чужие или незакоммиченные изменения. При конфликте с задачей остановись и обсуди его с человеком.
4. Выполни `git fetch` исходного репозитория. Создай `<login>/<task>` от актуального удалённого `dev`. Для существующей рабочей ветки влей актуальный `dev` обычным merge.

## Разработка

- Работа только в рабочей ветке. Не коммить непосредственно в `dev` и `master`.
- Не применяй `push --force`, `reset --hard`, удаление чужих веток и обход защиты.
- Не публикуй секреты, клиентские данные, внутренние документы, базы данных или материалы без разрешения.
- Не меняй настройки доступа, rulesets, теги, релизы, CI/deploy и владельцев без отдельной задачи владельца.
- Не создавай фиктивные проверки. Если приложение ещё не создано, прямо сообщи, что сборка и тесты отсутствуют.

## Завершение

1. Снова получи свежий `dev` исходного репозитория и влей его в рабочую ветку. Разреши конфликты, сохраняя изменения других разработчиков.
2. Выполни проверки, соответствующие проекту. Опиши команды, результат и ограничения.
3. Проверь diff на секреты, случайные файлы и изменения вне задачи. Создай осмысленные коммиты и push только рабочей ветки.
4. Создай PR **в `dev` исходного репозитория**. Опиши результат и способ проверки.
5. Сливай PR в `dev` только если человек поручил это, у аккаунта есть право записи и выполнены требования GitHub. Без этих условий передай ссылку на PR владельцу.
6. После слияния обнови чистую локальную `dev` через `pull --ff-only` (для fork — от исходного upstream/dev) и проверь именно получившуюся версию. Не стирай локальную работу ради переключения ветки.

`master`, публикация тегов, релизы и выкладка на сервер — только по отдельному явному поручению владельца. PR в dev не является разрешением на production.
