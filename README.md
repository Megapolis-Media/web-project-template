# Шаблон веб-проекта Megapolis Media

Стартовый репозиторий для командной разработки сайтов, в том числе с AI-ассистентами. Код приложения и технология сборки выбираются отдельно.

## Ветки

- `dev` — основная ветка разработки и ветка по умолчанию. Изменения только через pull request; обязательное одобрение пока не требуется.
- `master` — версия для production. Слияние только через PR владельцем репозитория. Сам по себе этот шаблон ничего не деплоит.
- `<github-login>/<task>` — рабочая ветка, например `ivan/header`. Одна задача — одна ветка.

В `master` и `dev` запрещены удаление, force push и прямые push. Работайте под своим аккаунтом.

## Начало работы

Читайте [CONTRIBUTING.md](CONTRIBUTING.md). AI-ассистент обязан прочитать [AGENTS.md](AGENTS.md).

Публичный репозиторий доступен для чтения всем. Без приглашения участник работает в fork и присылает PR. Для создания веток в исходном репозитории и самостоятельного слияния PR в `dev` нужен доступ на запись.

Для владельца: [создание проектов и администрирование](docs/MAINTAINERS.md).
